#include <stdio.h> #define MAX 10 #define INF 9999 int graph[MAX][MAX]; int n; void dijkstra(int source, int destination) { int distance[MAX], visited[MAX], parent[MAX]; int i, j, min, u; for (i = 0; i < n; i++) { distance[i] = INF; visited[i] = 0; parent[i] = -1; } distance[source] = 0; for (i = 0; i < n; i++) { min = INF; u = -1; for (j = 0; j < n; j++) { if (!visited[j] && distance[j] < min) { min = distance[j]; u = j; } } if (u == -1) break; visited[u] = 1; for (j = 0; j < n; j++) { if (!visited[j] && graph[u][j] != INF && distance[u] + graph[u][j] < distance[j]) { distance[j] = distance[u] + graph[u][j]; parent[j] = u; } } } // Reconstruct and display shortest path... }

Project Aim

To develop a Smart Emergency Evacuation & Rescue Route System that represents physical locations and interconnected roadways as a weighted graph, identifies the guaranteed shortest rescue path using Dijkstra's Algorithm, and manages emergency locations dynamically based on hazard status and roadway accessibility.

Algorithm (10-Step Specification)

  1. Step 1: Start from the emergency location (Source node).
  2. Step 2: Set its distance as 0.
  3. Step 3: Set all other distances as infinity (∞ / 9999).
  4. Step 4: Select the unvisited location having the smallest distance.
  5. Step 5: Check all connected neighbor locations.
  6. Step 6: Calculate the new cumulative distance.
  7. Step 7: If the new distance is smaller, update it and track parent pointer.
  8. Step 8: Mark the current location as visited.
  9. Step 9: Repeat until the rescue destination is reached or all nodes explored.
  10. Step 10: Output and display the shortest rescue route and distance in kilometers.
